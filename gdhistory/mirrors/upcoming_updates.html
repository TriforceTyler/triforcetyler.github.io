GD Upcoming Update Leaks

WARNING: SPOILERS! IF YOU DO NOT WANT UPCOMING FEATURES TO BE SPOILED, THEN DO NOT VIEW THIS PAGE!

Update 2.209

  • Geometry Dash 2.209 Trailer confirms all these features: emojis in comments, checkpoint saving for Platformer Mode, the More Games button getting replaced by "News", group chats in messages, Start Pos improvements (including naming Start Pos and setting the order), Start Pos switcher in the pause menu, custom keybinds, accessing Quests and Settings from the pause menu, searching in the friends list (and filters in the friends list), stats displays in the friends list, the View tab in the Editor where you can toggle different view settings (including new settings for Song Lines, BPM Lines, Keyframe Lines, LDM, and Select Filter), viewing level stats/Death Tracking, Editor button submenu popup things, better Edit tab in the Editor, naming Group IDs, scrollable list of Fonts, custom Folders for SFX, custom Editor grid size, previews of Easing types, auto-save and auto-backup, custom sounds for actions in the Editor, and so much more.
  • Start Pos switcher will have keybinds.
  • Parental Controls will be improved.
  • Improved comment reporting, w/ reason selecting (Inappropriate content, Harassment / Hate, Spam, Scam / Phishing, and Threats / Danger.
  • Info on Death Markers: local markers are your deaths, global markers are online players' deaths, Skull% died at this point, Wall% never got past this point, and in platformer Wall% died here and never beat the level.
  • Local death markers use your player color.
  • Your save on a platformer level will be deleted if the level gets updated. Level updates also delete global data on deaths, but the old data is saved for the creator to view.
  • Platformer level saving works on all platformer levels w/ checkpoints, not just post-2.209 levels.
