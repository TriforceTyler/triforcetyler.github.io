GD Upcoming Update Leaks

WARNING: SPOILERS! IF YOU DO NOT WANT UPCOMING FEATURES TO BE SPOILED, THEN DO NOT VIEW THIS PAGE!

Update 2.209

Trailer Features

  • Emojis.
  • Platformer Mode checkpoint saving.
  • The News button, replacing the More Games button.
  • Group chats, which include being able to share your levels.
  • Start Pos rework, with some new settings and the ability to name them. You can set a custom position for P1 and P2 to spawn. There is also an option called "Online" with unknown function. You can also set Y velocity.
  • Start Pos switcher, located in the pause menu.
  • Custom keybinds.
  • The View tab in the Editor, including some new settings (Song Lines, BPM Lines, Keyframe Lines, LDM, Select Filter).
  • New pause menu buttons. Two let you access Quests and Settings. One probably lets you access death markers. There are up arrow, clock, and spike buttons with unknown functions as well.
  • Friends list improvements, such as searching and displays of stats. Also includes a button for what looks like filters.
  • Submenu popup for some Editor buttons.
  • Reorganized Edit tab in the Editor.
  • Naming Group IDs.
  • Scrollable list of Fonts.
  • Custom folders for SFX.
  • Custom grid size in the Editor.
  • Previews of Easing types.
  • Auto-save and auto-backup.
  • Custom sounds for Editor actions, which can be toggled.
  • A friend icon in comments to indicate friends.
  • Support for multiple languages in comments.
  • An Editor button that probably hides the grid. There are also wrench and hide buttons which have unknown functions.
  • Settings menu rework, and new settings: Disable Auto Creator Controls, Disable Player Trail, Disable Wave Trail, Hitbox Trail On Death, Hitbox Trail Highlight, Disable Checkpoints, Skip Death Triggers, and Show Hitbox Trail.
  • Submenu for "My Stuff" in accounts, which includes your links to socials.
  • Exporting levels from the Editor.
  • Death markers, which can be viewed by the level creator from the Editor.
  • Tracking statistics for levels, including your death locations.
  • Friend limit increased from 400 to at least 934.

Other Confirmed Features

  • Start Pos switcher will have keybinds.
  • Parental Controls will be improved.
  • Improved comment reporting, w/ reason selecting (Inappropriate content, Harassment / Hate, Spam, Scam / Phishing, and Threats / Danger.
  • Info on Death Markers: local markers are your deaths, global markers are online players' deaths, Skull% died at this point, Wall% never got past this point, and in platformer Wall% died here and never beat the level.
  • Local death markers use your player color.
  • Your save on a platformer level will be deleted if the level gets updated. Level updates also delete global data on deaths, but the old data is saved for the creator to view.
  • Platformer level saving works on all platformer levels w/ checkpoints, not just post-2.209 levels.
  • Moderators will be changed to "Rating Advisors." Many Moderators were already demoted before the update, halving the Mod team.
