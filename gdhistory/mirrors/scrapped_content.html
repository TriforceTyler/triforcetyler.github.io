Info about scrapped content

  • Blue Coins, which were unused in the files of 1.9. Most likely the original appearance of User Coins.
  • As seen in "Geometry Dash Update 2.2 Particle System", there was an object that looked like some particles. This object is not present in 2.2.
  • The Safe was originally going to be directly in the Online Menu.
  • The Stop Jump Trigger and the Reverse Direction Trigger.
  • The main level Active.
  • The original platformer buttons were going to be reused from "Forlorn".
