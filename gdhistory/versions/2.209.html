2.209

Menus

  • Added 2 new Gauntlets: Duality and Paradox.
  • Social links on user profiles are now grouped into a Socials submenu.
  • A user's Jetpack is now shown on their profile seperately instead of being shown when their Ship is pressed.
  • Icons in Profiles can now be pressed to show their unlock method.
  • User profiles now display follower counts. The followers icon displays an info popup when pressed.
  • Follow user button redesigned.
  • New Search tab: Hyped.
  • Unrated filter for Lists.
  • Coins display in pause menu added.
  • Move to Top button changed into an arrow instead of a button.
  • Second page of Level Stats with Level Version, Object count, and exact upload and update times.
  • Improved Reporting system.
  • Statistics on usage of Songs.
  • Improved Settings menu.
  • Added submenu for a comment where you can copy the comment or report it.
  • Favoriting Songs.
  • Custom folders for SFX.
  • Added News, in the place of More Games.
  • 1 new reward chest for subscribing to Geometry Dash Spotlight.
  • Notifications system.
  • Improved Parental Controls system.
  • New account settings.
  • Account social links put into a submenu.
  • Improved Friends list.
  • New pause menu buttons to hide the pause menu, open Comments, open Quests, see settings for keybinds, and see settings for Death Markers
  • New settings: Disable Auto Creator Controls, Disable Player Trail, Disable Wave Trail, Hitbox Trail On Death, Hitbox Trail Highlight, Skip Death Triggers, Show Hitbox Trail, Disable Checkpoints, Show Info Label, and Disable Auto-Save Platformer.
  • Multiple settings renamed: Enable Faster Reset/Faster Reset, Enable Orb Guide/Orb Guide, Hide Practice Attempts/Hide Attempts, Enable Auto-Checkpoints/Auto-Checkpoints, Enable Quick Checkpoints/Quick-Checkpoints, Enable Death Effect/Death Effect, Enable Normal Music In Editor/Normal Music In Editor, Enable Low Detail/Low Detail, Enable Extra LDM/Extra LDM
  • Button in the settings to clear Platformer saves.
  • Custom scroll amount in settings.
  • New Editor settings: Legacy Move Menu, Disable Zoom Label, Hitbox Trail, Disable Anchor Snap, and Disable Pinch.
  • One Editor setting renamed: Enable Link Controls/Link Controls.
  • The progress bar in the pause menu now shows the amount of progress you've made compared to your best.
  • Modified Suggest Stars menu (for Rating Advisors).
  • Added the Moderation Queue (for Moderators).
  • Moderators can now remove levels from the servers, with a new menu to match.

Features

  • Added Emojis
  • Added Death Markers and Death Tracking.
  • Demon Keys can now be spent in the Safe to replay Daily, Weekly, and Event levels.
  • Added checkpoint saving for platformer levels.
  • Added group chats.
  • Custom keybinds, which can also be imported and exported.
  • Right clicking on your Search text now shows a small popup menu where you can copy, paste, or clear.
  • Added Start Pos switcher.

The Editor

  • The Percent Trigger.
  • The View tab.
  • Start Pos menu redone, with some new settings added.
  • New Particle textures, which are all the Emojis.
  • Particle textures are now split into pages.
  • Update description button now put inside of a Creator Settings submenu.
  • New Level settings: Enable CBS, Disable CBS, and Enable Platformer Saves.
  • Move to Bottom button.
  • Popup for when zoom is changed.
  • Moveable menu with some buttons for actions.
  • Custom grid size.
  • Button for the next free editor layer.
  • Smooth scrolling.
  • Button to hide the Editor UI.
  • Setting custom timewarp in the editor.
  • Viewing Death Markers.
  • Added button to download all audio assets.
  • Auto-saving.
  • Editor SFX and Editor Sound Packs.
  • D-Pad layout for the Edit tab.
  • Naming Group IDs, Control IDs, Item IDs, Enter Channel IDs, Block IDs, and Timer IDs.
  • Scrollable list of Fonts.
  • Changes to the Follow Player Y Trigger.
  • New Warp buttons.
  • Ignore Damage button in the pause menu for your levels only.
  • Previews for different Easing types.
  • Button in the Edit tab where you can set a custom move amount.
  • Improved Group ID searching menu in the Delete tab, with a tiny settings menu with just one setting.
  • Scrollable list of Group IDs in the Edit Group menu.

Miscellaneous

  • Some dots are now clickable.
  • Size of grouping buttons in the Editor decreased.
  • Support for multiple languages and special characters with the comment fonts.
  • Info popup to confirm blocking a user changed.
  • RobTop Gamer's achievement method changed to viewing the News menu, due to More Games being removed. The achievement name was not changed.
  • Normal Moderators are now called Rating Advisors. The M badge was changed to an A badge to match this. Clicking on the badge also now shows an info popup.
  • Removed More Games.
  • Removed Enable Quick Keys setting.
  • Removed the Songs button from the options menu.
