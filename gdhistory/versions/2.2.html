2.2

Since this update is so huge, not all the info on it is probably in here yet. This page is WIP.

Main Levels

  • Added new main level, Dash
  • Added The Tower
  • Added 4 Platformer main levels to The Tower: The Tower, The Sewers, The Cellar, and The Secret Hollow

Menus

  • Added Lists
  • Added featured Lists
  • Added Paths (aka Paths of Power)
  • Added grayed-out buttons for the postponed features: Versus, Event Levels, and the Map
  • Redesigned the Treasure Room menu
  • Added more 1 and 5-key chests to the Treasure Room
  • Added 10, 25, 50, and 100-key chests to the Treasure Room
  • Added 2 new shops: the Mechanic and the Diamond Shop
  • Added 5 new Gauntlets: World, Galaxy, Universe, Discord, and Split Gauntlets
  • Abbreviated level download and like counts
  • Added more links to RobTop's socials (Twitch, Discord, and Reddit)

New Features

  • Added Legendary and Mythic ratings
  • Added Platformer levels
  • Added Swing gamemode
  • Added free fly mode for the Ship, UFO, Ball, Swing, Wave, and Spider (and the Dual Portal as well)
  • Added over 700 new Icons: 484 Cubes, (unknown) Ships, 76 Balls, (unknown) UFOs, 51 Waves, 27 Robots, 7 Trails, and (unknown) Colors
  • Added Robot and Spider Animations
  • Added Ship Fires
  • Added Music Customizer and Music Unlocker
  • Added FPS option to Steam
  • Added more Vault codes
  • Added Tier 2 Shards: Earth, Metal, Blood, Light, and Soul
  • Added Tier 2 Bonus Shards
  • Added Diamond Shards currency, which are spent in the Diamond Shop
  • Added customizable player Glow colors
  • Added new color menu

Level Editor

  • Added 86 total new Triggers: Reverse Trigger, Background Change Trigger, Ground Change Trigger, Middle Ground Change Trigger, Middle Ground Trigger, Background Speed Trigger, Middle Ground Speed Trigger, Spawn Particle Trigger, item triggers (Edit, Compare, and Persist), Gradient Trigger, advanced follow triggers (normal, Edit, and Re-Target), camera triggers (Zoom, Static, Offset, Edge, Rotate, Guide, and Mode), Random Trigger, Advanced Random Trigger, End Trigger, Options Trigger, Player Control Trigger, area triggers, Scale Trigger, Gravity Trigger, gameplay direction trigger, TimeWarp Trigger, shader triggers (Shock Wave, Shock Line, Chromatic, Chromatic Glitch, Pixelate, Lens Circle, Radial Blur, Motion Blur, Bulge, Pinch, Gray Scale, Sepia, Invert Color, Hue, Edit Color, and Split Screen), Shader Trigger, Keyframe Trigger, Event Trigger, Song Trigger, Edit Song Trigger, SFX Trigger, and Edit SFX Trigger
  • Added Force Blocks
  • Added Autobuild blocks
  • Added F Block
  • Added Particle Object and particle editor
  • Added many new animated objects
  • Added an insane amount of pixel objects, in a new pixel tab
  • Added Keyframes
  • Added many new pixel pickups
  • Added Checkpoint
  • Added particle texture objects (essentially just each texture you can use in the particle editor has also been added as an object), including all of the difficulty faces and some other GD sprites
  • Added Counter Label

Editor Features

  • Added the Extras and Extras2 tabs to Edit Group menu
  • Added new Editor options
  • Set the object limit to 40,000, which can then be raised to 80,000 and then removed entirely
  • Increased the max group ID to 9,999
  • Added the X and Y Scale tool
  • Added the Warp tool
  • Added dynamic height option
  • Added 39 new backgrounds
  • Added 5 new grounds
  • Added middle grounds, with 3 available
  • Removed some Editor tabs and added some new Editor tabs
  • Added 1 or 2 new Z layers
  • Added sound effects

Other Editor Changes

  • Reworked the Spawn Trigger, adding many new options
  • Organized the level settings menu, putting speed and gamemode into submenus
  • Relabled Spawn and Touch Triggered in almost every trigger's menu to say Trigger instead of Triggered
  • Teleport Portals can now be separated
  • Added RGB and HEX code values to color selection
  • Added Override Count option to the Pickup Trigger
  • The value for Fade Time in the Alpha Trigger can now be typed in
  • Transition triggers can now be spawn triggered and touch triggered
  • Replaced many of the placeholder info popups for many of the 2.1 triggers with actual info
  • Collision blocks can now use the player instead of BlockA or BlockB

Other Changes

  • Fixed some gameplay mechanics being affected by FPS
  • Added loading animation for levels on the play button (user levels only)
  • Custom song IDs can now be up to 15 digits long
  • Players can now link their social accounts, as well as 1 custom domain
  • Added colorblind-friendly Portal and Orb labels
  • Added a setting showing 2-decimal percentage
  • Removed support for Everyplay
  • Removed the Hall of Fame
  • Removed the Game Center button, which was only visible on iOS
  • Player glow no longer blends with the background
