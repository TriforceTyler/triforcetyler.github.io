2.205

Note: this update was not released on Steam, since all the features added in this update were already added to Steam previously.

  • Added in-depth menu for Stars and Moons on User Profiles, detailing how many levels of each difficulty a user completed, as well as daily and gauntlet levels
  • Added in-depth menu for Demons on User Profiles, detailing how many level of each demon difficulty a user completed, as well as weekly and gauntlet levels
  • Added customization for the location of the Practice Mode buttons (similar to the Platformer buttons)
  • Added coyote time to Platformer mode
  • Added Practice Mode for Platformer mode
  • Added Show Hitboxes in Practice option
  • Added new Gauntlets
  • Added info popup to profiles, showing a list of statistics without rounding
  • Changed prices of multiple items:
  • Music Changer: 100,000 -> 40,000 Mana Orbs
  • Music Unlocker: 5,000 -> 2,000 Diamond Shards
  • Unlock Path: 50,000 -> 25,000 Mana Orbs
  • Added fast menu (reduced menu transition time)
  • Added borderless full screen
  • Added optional player hitbox viewing in Practice Mode
  • Decreased Platformer air friction
  • Removed the ability to require a password to copy levels; all levels from this version onward are free to copy
  • Added more options for sliding in Platformer levels
