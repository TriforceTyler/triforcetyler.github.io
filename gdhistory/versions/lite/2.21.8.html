Lite 2.21.8

  • Added group chats, which are only accessible in the full version.
  • Added News, which is located next to the Newgrounds button.
  • Added Emojis.
  • Added checkpoint saving for platformer levels.
  • Added Death Markers and Death Tracking.
  • Added Full Version button to level select.
  • Added Remove Ads button to the screen that shows up when you die and Auto-Retry is disabled.
  • Users can only be followed in the full version.
  • Social links on user profiles are now grouped into a Socials submenu.
  • A user's Jetpack is now shown on their profile seperately instead of being shown when their Ship is pressed.
  • Icons in Profiles can now be pressed to show their unlock method.
  • User profiles now display follower counts. The followers icon does not display an info popup when pressed.
  • Follow user button redesigned.
  • Coins display in pause menu added.
  • Second page of Level Stats with Level Version, Object count, exact upload and update times, and your attempt progress.
  • First page of Level Stats now shows your clicks and time on your best attempt.
  • Improved Reporting system.
  • Statistics on usage of Songs.
  • Improved Settings menu.
  • Added submenu for a comment where you can copy the comment or report it.
  • Daily, Weekly, and Event levels now have a red exclamation mark when there is a new Daily/Weekly/Event available.
  • 1 new reward chest for subscribing to Geometry Dash Spotlight.
  • Improved Parental Controls system. The button is labeled Parental instead of Parent.
  • New account settings. The Group Chat settings are inaccessible.
  • Account social links put into a submenu.
  • Improved Friends list.
  • Favoriting Songs.
  • New pause menu buttons to hide the pause menu, open Comments, open Quests, and see settings for Death Markers.
  • New settings, and some settings were also renamed.
  • Button in the settings to clear Platformer saves.
  • The progress bar in the pause menu now shows the amount of progress you've made compared to your best.
  • Modified the Song info menu.
  • Added button to the pause menu that opens a settings menu for the Practice UI. It only appears when Practice Mode is active.
  • Level IDs and Song IDs can now be copied by clicking on the ID.
  • New Level settings: Enable CBS, Disable CBS, and Enable Platformer Saves.
  • Added support for multiple languages and special characters with the comment fonts.
  • Info popup to confirm blocking a user changed.
  • RobTop Gamer's achievement method changed to viewing the News menu, due to More Games being removed. The achievement name was not changed.
  • Normal Moderators are now called Rating Advisors. The M badge was changed to an A badge to match this. Clicking on the badge also now shows an info popup.
