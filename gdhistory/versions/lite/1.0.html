Lite 1.0

All features present in version 1.0 of Geometry Dash Lite.

  • Stereo Madness.
  • Buttons for the trailer and the full version popup.
  • More Games button, which includes Geometry Dash, Boomlings, Boomlings Matchup, and Memory Mastermind in the menu.
  • Options menu, including Support, Rate, Download Soundtracks, and How to Play. Also includes two buttons to toggle Music and SFX.
  • Statistics, including Total Jumps, Total Attempts, Completed Levels, and Completed Online Levels.
  • No icon customization.
  • Practice Mode, button to toggle Auto Checkpoints, and a Help button in the pause menu as well (which takes you to How to Play).
  • No achievements.
  • Download Soundtracks page, which does still let you download all songs from the main game up to that point (up to Cycles).
